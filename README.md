# LNIM - VS Code 局域网即时通讯扩展

![Version](https://img.shields.io/badge/version-0.0.3-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**LNIM**（Local Network Instant Messenger）是一个轻量级的 VS Code 扩展，为局域网内的开发者提供零配置的 P2P 通信解决方案。基于 TCP 协议，在团队成员之间快速共享消息、文件路径和实际文件内容。

## ✨ 功能特性

### 核心通讯功能
- **💬 即时聊天** - 基于 TCP 的实时文本消息交互，支持多联系人对话和聊天历史记录
- **👥 联系人管理** - 手动添加局域网内的同事（IP:Port），实时显示在线状态
- **🔄 自动发现** - 当远端主机主动连接时，自动将其添加到联系人列表

### 文件与资源共享
- **📂 文件路径共享** - 在文件浏览器中右键点击文件/文件夹，通过"通过LNIM发送"命令快速分享相对路径
- **📥 文件接收** - 接收来自联系人发送的实际文件，并保存到本地
- **📋 文件管理** - 独立的文件管理面板，查看已接收的文件、打开或删除

### 用户体验
- **🎨 现代化界面** - 多标签设计：聊天、联系人、文件、设置
- **💾 持久化存储** - 自动保存聊天历史、联系人列表和接收的文件
- **🔗 工作流集成** - 文件资源管理器右键菜单，无需离开编辑器

## 🚀 快速开始

### 1. 安装扩展
在 VS Code 扩展市场中搜索 `vscode-lnim` 并安装。

### 2. 初始配置
1. 点击活动栏上的 **LNIM** 图标打开扩展面板
2. 切换到 **设置** 标签页
3. 配置您的昵称（显示名称）
4. 确认通信端口（默认 18080）
5. 您的本地 IP 地址会自动检测并显示

### 3. 添加联系人
1. 切换到 **联系人** 标签页
2. 在"主机地址"输入框中输入对方的 IP 和端口（格式：`IP:Port`，例如 `192.168.1.100:18080`）
3. 点击搜索按钮或按 Enter 建立连接
4. 当对方运行扩展并连接成功，会显示其昵称和在线状态

### 4. 开始通讯
1. 在 **聊天** 标签页左侧选择要交流的联系人
2. 输入消息后按 Enter 或点击发送
3. 支持使用 @ 符号提及特定联系人（输入 `@` 查看列表）

### 5. 文件共享
- **分享文件路径**：在文件浏览器中右键选择文件/文件夹 → "通过LNIM发送"，会插入相对路径到聊天框
- **发送文件**：在聊天框的工具栏点击文件图标选择本地文件，通过消息发送给指定联系人
- **接收文件**：接收到文件后在 **文件** 标签页中查看，点击即可打开，或右键删除

## ⚙️ 配置说明

扩展在 **设置** 页面提供以下配置项：

| 配置项 | 描述 | 默认值 |
|--------|------|--------|
| **昵称** | 您在网络中的显示名称，用于识别身份 | - |
| **端口** | 本地监听的 TCP 端口 | 18080 |

## 📂 数据存储

所有数据保存在 VS Code 的全局存储目录：
- **聊天记录** - JSON 格式存储每个联系人的消息历史
- **联系人列表** - 包含 IP、端口、昵称和在线状态
- **接收的文件** - 存放在 `files/` 子目录中

## 🔒 安全与隐私

- ✅ **本地通信** - 所有数据仅在局域网内通过 TCP 传输，不经由任何云端
- ✅ **无账户依赖** - 无需注册账户或第三方登录
- ✅ **离线工作** - 完全离线运行，无网络依赖
- ⚠️ **无加密** - 目前消息未加密，仅用于信任的内网环境

## 📋 系统要求

- VS Code 1.108.0 或更高版本
- 同一局域网环境
- 双方防火墙允许 TCP 连接（默认端口 18080）
- 支持 Windows、macOS、Linux

## 💡 使用建议

1. **端口配置** - 如果默认 18080 被占用，在设置中修改为其他可用端口，然后重启扩展
2. **文件大小** - 暂无文件大小限制，但大文件传输可能需要较长时间
3. **网络延迟** - 局域网内正常使用，跨域网络可能不稳定
4. **多设备** - 可同时在多个 VS Code 实例运行，彼此独立

## ⚠️ 已知限制

- **局域网仅限** - 只支持同一 LAN 内的通信，不支持跨广域网
- **非持久连接** - 联系人列表需手动添加，暂不支持自动发现整个网络
- **TCP 限制** - TCP 连接关闭后需要重新添加联系人才能连接
- **聊天记录** - 记录仅保存在本地，不同设备间无法同步

### 项目结构
```
src/
├── extension.ts                 # 扩展入口点
├── chat_view_provider.ts        # WebView 提供者和主要业务逻辑
├── chat_message_service.ts      # TCP 服务器和通讯管理
├── chat_message_manager.ts      # 聊天消息存储和历史记录
├── chat_contact_manager.ts      # 联系人管理
├── chat_file_service.ts         # 文件接收和管理
├── chat_data_store.ts           # 持久化存储
└── test/                        # 测试文件

resources/
├── chat.html/js/css             # 聊天界面
├── contacts.html/js             # 联系人管理界面
├── files.html/js                # 文件管理界面
└── settings.html/js             # 设置界面
```
